# 项目库统计程序

实验室项目库的**多人协作**系统：内网多人同时访问、按角色分权。
管理员维护项目库并导出统计表，实验员在对应平台板块填报当月完成的项目。

## 功能与权限

| 能力 | 管理员 | 细胞 / 分子 / 病理 / 动物 | 运营 / 设计 |
|---|:---:|:---:|:---:|
| 仪表盘与项目库统计查询 | ✅ | ✅ | ✅ |
| 浏览项目库 | ✅ | ✅（只读） | ✅（只读） |
| 平台完成状态下拉填报 | ✅（全部平台） | ✅（仅自己平台） | ❌ |
| 月末统计填报 | ✅（全部板块） | ✅（仅自己平台） | ❌ |
| 创建 / 删除月份、锁定填报 | ✅ | ❌ | ❌ |
| 导出统计 Excel | ✅ | ❌ | ❌ |
| 项目库增 / 删 / 改、导入数据源 | ✅ | ❌ | ❌ |
| 用户管理 / 系统设置 / 清空项目库 | ✅ | ❌ | ❌ |

**六种岗位**：细胞 / 分子 / 病理 / 动物 为填报岗位，运营 / 设计 为**只读岗位**（全程只能查看，不能填任何板块）。
自助注册一律为普通用户，管理员账号只能由已有管理员创建。

## 项目库

- **四类项目库**：真实、加急、库存、返修。可按类型 / 平台 / 完成状态筛选，支持按编号或项目名搜索，支持编号正序 / 倒序。
- **平台状态语义**：`空白` = 已设计未完成（计入未完成）｜`/` = 未设计（不参与完成判定）｜`✅` = 完成｜`❌` = 未完成。
  只有被设计的平台全部完成，项目才算完成。
- **行内填报**：有权限的平台，直接在下拉里改完成状态，不必进编辑弹窗。
- **列宽可拖拽**：鼠标放到表头右边界拖动即可调整，**按浏览器记住**；双击该边界恢复单列默认宽度，
  工具栏「重置列宽」一次恢复全部。项目名列默认自动占满剩余宽度。
- **报价列**只显示报价金额（返修不计价显示 `—`），返修要求等内容统一显示在「备注」列。
- **导出二选一**：导出时可选 **下载到本机**（浏览器直接下载到当前电脑）或 **保存到服务器**
  （留在服务器导出目录并给出下载入口）。
- 每一行**等高**，不受角色或状态影响。

## 月末项目统计

1. 管理员新建月份（如「2026年9月」）。
2. 各平台实验员在自己平台的板块里添加当月完成的项目编号，并选择所属类型（真实 / 加急 / 库存 / 返修）。
3. 管理员确认填完后**导出统计表**，生成一张按月分平台的标准 Excel。
4. 需要收口时管理员可**锁定填报**，锁定后任何人都不能再改。

导出表版式：标题区 → 四个平台分区（细胞 / 分子 / 病理 / 动物）→
每区内按类型列出编号、项目名、报价与类型标记，库中查不到的编号会标红提示。

## 工作日志

每个账号可记录自己的工作日志（日期、标题、内容），只能查看和管理自己的日志。

## 项目库数据

程序**不内置任何项目库数据**，新实例的项目库是空的，由管理员在「导入项目库」里
上传信息表自行导入（也可逐条手工录入）。

导入的信息表按 sheet 名识别类型（真实 / 加急 / 库存 / 返修），
导入时会把源文件另存一份副本到数据目录的「导入源文件」里备查。
需要推倒重来时，管理员可在「设置 → 数据维护 → 清空项目库」清空全部项目
（不影响用户账号、系统设置与月末统计填报）。

## 部署（Docker）

### 方式一：直接用已发布镜像（推荐，不需要源码和构建）

```bash
docker compose up -d          # 拉取 xuthsand/projlib:latest 并启动
```

启动后访问 `http://<主机IP>:8775`，数据落在 compose 文件同级的 `./data`。
首次启动只自动创建内置管理员账号，**项目库是空的**，登录后用「导入项目库」导入自己的数据。

想改端口 / 数据目录，不必改 compose 文件，同目录放一个 `.env` 即可：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PROJLIB_PORT` | `8775` | 宿主机端口（右边容器端口 8775 不要改） |
| `PROJLIB_DATA` | `./data` | 宿主机数据目录（数据库 / 导出文件 / 导入副本） |
| `PROJLIB_TAG` | `latest` | 镜像标签（`latest` / `edge` / `v1.0.0`） |
| `PROJLIB_IMAGE` | `xuthsand/projlib` | 镜像地址 |
| `TZ` | `Asia/Shanghai` | 时区 |

镜像同步发布在 `ghcr.io/fujiwareshine/projlib`，内网拉不到 Docker Hub 时把
`PROJLIB_IMAGE` 换成它即可，其余不用动。

### 方式二：从源码本地构建（内网无外网 / 改了代码要生效）

```bash
docker compose -f docker-compose.build.yml up -d --build
```

> 两种方式用同一个 compose 项目名 `projlib`，是二选一关系，不要同时起。

### 更新版本

```bash
docker compose pull && docker compose up -d
```
